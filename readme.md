Telecom Customer Churn Analysis Dashboard

Project Overview

This project presents an interactive Power BI dashboard developed to analyze customer churn behavior in a telecom company. The objective is to identify factors influencing customer attrition and generate actionable business insights that can help improve customer retention.


Business Problem

Customer churn is a major challenge for telecom companies as acquiring new customers is often more expensive than retaining existing ones.

This project aims to:

* Analyze customer demographics and service usage.
* Compare churned and retained customers.
* Identify key churn drivers.
* Support data-driven retention strategies.
* Visualize customer behavior through an interactive dashboard.

Key Insights

Customer Profile

* Total Customers: 7,043
* Average Monthly Charges: 64.76
* Average Total Charges: 2,283

Churn Profile

* Total Churned Customers: 1,869
* Average Monthly Charges: 74.44
* Average Total Charges: 1,532

Major Findings

1. Month-to-month contracts exhibit the highest churn rates.
2. Customers with shorter tenure are more likely to leave the company.
3. Fiber optic internet users show relatively higher churn behavior.
4. Customers using electronic check payments demonstrate increased churn rates.
5. Long-term contracts contribute significantly to customer retention.
